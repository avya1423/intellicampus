# IntelliCampus - AI Smart Campus & Student Risk Analytics

Full-stack smart campus management platform with a clean Light Theme, Role-Based Access Control (Admin, Teacher, Student), Predictive Risk Engine, and Google Gemini AI Advisor.

## Quick Setup
1. **Backend:** `cd backend && npm install && cp .env.example .env` -> Add `MONGO_URI` & `GEMINI_API_KEY` -> `npm run seed` -> `npm run dev`
2. **Frontend:** `npm install && npm run dev`
